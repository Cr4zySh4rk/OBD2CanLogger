ECU Map Table — Live · RPM × Load

Reconstructed calibration table in standard tuning-software layout: RPM breakpoints across, engine load down (high load on top), one median value per cell, updating live as you drive — cells flash cyan when their value changes, and only the RPM/load range you've actually hit is shown. Hover any cell for sample count and range; italic cells have fewer than 3 samples (low confidence). The Total Fuel Correction table is the tuner's money map — it shows where the factory fuel table is off: positive = running lean (ECU adding fuel), negative = rich (ECU pulling fuel). Corrections beyond ±5 % in a well-hit cell mark a zone worth correcting.
